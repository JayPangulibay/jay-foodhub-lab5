\# Jay FoodHub



Jay FoodHub is a mobile food delivery application prototype inspired by modern food delivery platforms.



\## Features



\- User login

\- Home screen

\- Food browsing

\- Food ordering

\- Activity/order tracking

\- Simple and user-friendly mobile interface



\## Technologies Used



\- React Native

\- Expo

\- JavaScript

\- Figma

This project was created as part of a mobile application development project.
